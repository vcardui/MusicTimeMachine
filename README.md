# 🎧**Music Time Machine**

Create a Spotify playlist for your special date based Billboard Hot 100™ 

## 🎯 Objective

Generate a playlist by performing web scraping on the Billboard Hot 100™ chart and efficiently integrating songs through Spotify’s API.

## 🙌 Project Personal Milestones

- Performed web scraping through a Billboard Hot 100 weekly chart website to gather song and artist data based on a specific date provided by user.
- Successfully authenticated and interacted with Spotify’s API. Created playlist, searched for songs verifying title and artist matched, inserted songs and published by fully automated process.

## 💡 Inspiration for creating this project

I’m currently enrolled in 100 Days of Code: The Complete Python Pro Bootcamp (Udemy) and this is the course’s #46th project. Provided Spotify is one of the biggest music Streaming Platforms, creating a playlist generator was a perfect opportunity for interacting with the platform’s API and elevated my authentication skills.

## 👀 About the project

Had a bit of a headache during the authentication process for interacting with Spotify’s API, particularly regarding the understanding of scope. Realized once again that it is more efficient and cost-effective to thoroughly read the documentation until it is fully understood. Furthermore, adding songs proved to be a bit tricky due to the prevalence of identical song titles among various artists.

The web scraping process also presented challenges due to the HTML structure of the Billboard website; I had to manage multiple exceptions and adapt to its constantly changing format.

Nevertheless, the satisfaction that came along with the final product was priceless! Now I can go back in time to special days of my life by listening to amazing music.

I last worked on this project December 25th, 2023
